# Intrusion Detection System (IDS) using Mininet and Scapy

## Description
This project implements a simple Intrusion Detection System (IDS) to monitor network traffic and detect suspicious activities in a simulated environment.

## Tools & Technologies
- Kali Linux
- Mininet
- Ryu Controller
- Python
- Scapy
- VMware

## Features
- Real-time packet monitoring
- Detection of abnormal traffic
- DoS attack detection
- Traffic analysis per IP
- Alert generation system

## Implementation Steps
1. Install required packages
2. Run Ryu Controller
3. Start Mininet topology
4. Test network connectivity
5. Run IDS Python script
6. Monitor packets and detect attacks

## Result
The IDS successfully detected suspicious traffic and generated alerts when abnormal packet thresholds were exceeded.

## Conclusion
This project demonstrates how Scapy and Mininet can be used together to build a basic IDS for cybersecurity learning and network monitoring.
